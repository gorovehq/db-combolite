1. Diagnostic Status Codes (cdb_common.h)

Every fallible function in db-combolite returns a strongly typed cdb_status enumeration integer. CDB_OK (0) denotes total success; negative integers designate deterministic failure conditions.

Status Enum Value Plain English Diagnostic Meaning
CDB_OK0The operation completed successfully without errors.
CDB_E_INVALID_ARG-1A required pointer argument was NULL, or an integer parameter fell outside its permitted range.
CDB_E_BUFFER_TOO_SMALL-2The caller-allocated destination buffer has insufficient capacity. The needed byte size is usually written to an output length parameter.
CDB_E_TRUNCATED-3The input stream, payload, or file ended unexpectedly before all declared structure bytes were read.
CDB_E_MALFORMED-4The binary payload violated format rules, corrupted header tags, or unparseable structures.
CDB_E_NOT_CANONICAL-5Input encoding is valid but does not adhere to the single canonical encoding format (Spec 14.6.5).
CDB_E_OVERFLOW-6A numeric computation, key length, or index width exceeded allowable type boundaries.
CDB_E_DEPTH-7JSON-like nested objects or arrays exceeded the maximum permitted recursion depth (32 levels).
CDB_E_STATE-8The requested API call is invalid in the current engine state (e.g. attempting to insert rows without an active transaction).
CDB_E_UNSUPPORTED-9The feature, algorithm, or compression mode is recognized but disabled in the current build configuration.
CDB_E_IO-10The underlying storage medium, disk controller, or filesystem reported an I/O fault or write barrier failure.
CDB_E_NOT_FOUND-11The named store, file, column, index, entry ID, or key was not located in the catalog or index.
CDB_E_READ_ONLY-12A mutation was attempted on read-only storage, a closed transaction, or a read-only snapshot.
CDB_E_CORRUPT-13A checksum, CRC32C, or cryptographic AEAD authentication tag failed verification.
CDB_E_EXISTS-14The requested store name, unique index key, or primary key is already occupied.
CDB_E_SCHEMA-15A document or row violated the store's registered schema rules (e.g. missing NOT NULL field).
CDB_E_BUSY-16Another process holds the reconciliation baton or coordinator claim.
CDB_E_COLLISION-17A concurrent transaction committed an edit to the identical entry or unique key.
CDB_E_TIMEOUT-18A timed condition variable, mutex acquisition, or coordinator election exceeded its deadline.
CDB_E_OUT_OF_BUDGET-19A query or stored procedure exceeded its allocated instruction step or memory budget.
CDB_E_SECURITY-20Access denied by RBAC permission check, expired key rotation, or invalid enclave master key.

2. Multi-Model CRUD Implementation Cookbook

Runnable C99 recipes for Create, Read, Update, and Delete operations across all storage models.

2.1 Relational Tables CRUD Recipe

/* 1. CREATE: Insert a new row */
cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
uint8_t row[256];
cdb_value_writer w;
cdb_value_writer_init(&w, row, sizeof(row), CDB_ORDER_LITTLE);
cdb_value_begin_object(&w);
cdb_value_field(&w, col_id_user);
cdb_value_write_string(&w, "Alice", 5);
cdb_value_field(&w, col_id_score);
cdb_value_write_f64(&w, 95.0);
cdb_value_end_object(&w);

uint64_t entry_id = 0;
cdb_status s = cdb_table_insert(&db, table_id, row, cdb_value_writer_len(&w), &entry_id);
cdb_tx_commit(&db);

/* 2. READ: Point lookup by Primary Key */
int found = 0;
uint64_t found_entry = 0;
s = cdb_table_find(&db, table_id, pk_wire, pk_wire_len, &found_entry, &found);

/* Read entire committed row content */
uint8_t row_buf[512];
size_t row_len = 0;
s = cdb_table_get(&db, table_id, found_entry, row_buf, sizeof(row_buf), &row_len);

/* 3. UPDATE: Partial column delta update */
cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
uint8_t delta_row[128];
cdb_value_writer_init(&w, delta_row, sizeof(delta_row), CDB_ORDER_LITTLE);
cdb_value_begin_object(&w);
cdb_value_field(&w, col_id_score);
cdb_value_write_f64(&w, 98.5);
cdb_value_end_object(&w);

s = cdb_table_update(&db, table_id, found_entry, delta_row, cdb_value_writer_len(&w));
cdb_tx_commit(&db);

/* 4. DELETE: Remove row */
cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
s = cdb_table_delete(&db, table_id, found_entry);
cdb_tx_commit(&db);

2.2 Document Pools CRUD Recipe

/* 1. CREATE: Insert document */
cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
uint64_t doc_id = 0;
s = cdb_doc_insert(&db, pool_id, "Article summary", 15, body_bytes, body_len, &doc_id);
cdb_tx_commit(&db);

/* 2. READ: Read head revision */
uint8_t doc_buf[4096];
size_t doc_len = 0;
cdb_doc_info info;
s = cdb_doc_get(&db, pool_id, doc_id, 0, doc_buf, sizeof(doc_buf), &doc_len, &info);

/* 3. UPDATE: Apply JSON patch */
cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
s = cdb_doc_patch(&db, pool_id, doc_id, patch_bytes, patch_len);
cdb_tx_commit(&db);

/* 4. DELETE: Tombstone document */
cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
s = cdb_doc_delete(&db, pool_id, doc_id);
cdb_tx_commit(&db);

3. Environment & Storage Abstraction (cdb_env.h, cdb_storage.h)

cdb_hostenv_init STATUS

Initializes a cdb_hostenv structure and populates the provided cdb_env structure with standard POSIX system call hooks (open, pread, pwrite, fsync, monotonic clock).

void cdb_hostenv_init(cdb_hostenv *he, cdb_env *out);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st he cdb_hostenv* [In/Out] Pointer to caller-owned tracking memory that maintains open host file descriptors. Must not be NULL. Holds up to 16 concurrent file descriptors. Caller owned. Must outlive all database instances using this environment.
2nd out cdb_env* [Out] Destination environment structure receiving operation function pointers. Must not be NULL. Caller allocated struct.

Returns: None (void).

C99 Usage Example: 
cdb_hostenv he;
cdb_env env;
cdb_hostenv_init(&he, &env);
cdb_hostfile_open STATUS

Opens the file located at path with caller-specified access flags (create, read/write, truncate) and initializes a cdb_storage interface structure with direct POSIX pread/pwrite/fsync vtable methods.

cdb_status cdb_hostfile_open(cdb_hostfile *hf, const char *path, unsigned flags, cdb_storage *out);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st hf cdb_hostfile* [In/Out] Pointer to hostfile context tracking internal OS file descriptor. Must not be NULL. Caller owned.
2nd path const char* [In] POSIX filesystem path to the database archive or companion file. Valid null-terminated filesystem path. Caller owns string buffer.
3rd flags unsigned [In] Bitmask of file opening flags. CDB_STORAGE_READ (1), CDB_STORAGE_WRITE (2), CDB_STORAGE_CREATE (4), CDB_STORAGE_TRUNC (8). Passed by value.
4th out cdb_storage* [Out] Pointer to storage structure receiving virtual function pointers and context. Must not be NULL. Caller allocated struct.

Returns: CDB_OK on successful open; CDB_E_IO if OS file open fails; CDB_E_INVALID_ARG if path or pointers are NULL.

C99 Usage Example: 
cdb_hostfile hf;
cdb_storage st;
cdb_status s = cdb_hostfile_open(&hf, "data.cdb", CDB_STORAGE_READ | CDB_STORAGE_WRITE | CDB_STORAGE_CREATE, &st);
cdb_storage_read READ

Reads exactly len bytes from physical storage at byte offset offset into caller-allocated buffer buf. Handles short reads transparently until the entire request is satisfied or EOF is reached.

cdb_status cdb_storage_read(const cdb_storage *s, uint64_t offset, void *buf, size_t len);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st s const cdb_storage* [In] Storage handle containing operations table and backend context. Must be properly initialized. Caller owned handle.
2nd offset uint64_t [In] Absolute byte offset from the start of the storage medium. 0 to storage capacity minus len. Passed by value.
3rd buf void* [Out] Caller destination buffer receiving read bytes. Must have capacity of at least len bytes. Caller buffer.
4th len size_t [In] Exact count of bytes to read. > 0. Passed by value.

Returns: CDB_OK on total read success; CDB_E_IO on hardware/OS read failure; CDB_E_TRUNCATED if file ends prematurely.

C99 Usage Example: 
uint8_t page[4096];
cdb_status s = cdb_storage_read(&st, 0, page, sizeof(page));
cdb_storage_program UPDATE

Writes exactly len bytes to storage at offset offset. Designed for write-once append semantics on NOR flash or in-place sector writes on block storage.

cdb_status cdb_storage_program(cdb_storage *s, uint64_t offset, const void *buf, size_t len);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st s cdb_storage* [In/Out] Storage handle. Must be initialized with CDB_STORAGE_WRITE. Caller owned handle.
2nd offset uint64_t [In] Absolute byte offset for writing. Aligned to backend write granularity (typically 1, 4, or 4096). Passed by value.
3rd buf const void* [In] Source buffer containing bytes to write. Must hold at least len valid bytes. Caller owned buffer.
4th len size_t [In] Byte length of payload to write. > 0. Passed by value.

Returns: CDB_OK on successful write; CDB_E_IO on write error; CDB_E_READ_ONLY if storage was opened read-only.

C99 Usage Example: 
cdb_status s = cdb_storage_program(&st, 4096, page_data, 4096);
cdb_storage_sync UPDATE

Forces all cached operating system and drive controller write buffers to non-volatile physical storage media. Essential for ACID durability fences before releasing commit markers.

cdb_status cdb_storage_sync(cdb_storage *s);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st s cdb_storage* [In/Out] Storage handle. Must be open and write-capable. Caller owned handle.

Returns: CDB_OK when disk caches are fully flushed; CDB_E_IO if hardware flush fails.

C99 Usage Example: 
cdb_status s = cdb_storage_sync(&st);

4. Database Lifecycle & Maintenance (cdb_db.h)

cdb_db_open CREATE

Mounts the main archive file, reads the 32-byte header, verifies byte order and page size, checks coordinator lock files, verifies zero-heap caller buffers, and replays uncommitted WAL or delta tracks.

cdb_status cdb_db_open(cdb_db *db, const cdb_db_config *cfg);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [Out] Pointer to caller-allocated database context structure. Must not be NULL. Caller allocated struct.
2nd cfg const cdb_db_config* [In] Configuration structure containing paths, environment, memory pools, page sizes, and encryption keys. Must specify valid env, storage, and caller buffers. Caller owned struct.

Returns: CDB_OK on successful open; CDB_E_INVALID_ARG on NULL pointers or invalid buffer sizes; CDB_E_MALFORMED on header corruption; CDB_E_IO on disk error; CDB_E_BUSY if locked by another coordinator.

C99 Usage Example: 
cdb_db db;
cdb_db_config cfg = { .env = &env, .storage = &st, /* buffers */ };
cdb_status s = cdb_db_open(&db, &cfg);
cdb_db_close STATUS

Flushes dirty pages from cache, reconciles staged deltas, synchronizes secondary companion files (WAL, vector index, FTS lexicon), releases multi-process coordinator baton slots, and zeroes secure memory.

cdb_status cdb_db_close(cdb_db *db);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Pointer to open database handle. Must be currently open and valid. Caller owned struct.

Returns: CDB_OK on clean close; CDB_E_IO if final page flush or lock release encounters an error.

C99 Usage Example: 
cdb_status s = cdb_db_close(&db);
cdb_db_compact UPDATE

Iterates across free-space freelists, migrates live B+Tree nodes and document revision chains to contiguous page ranges, frees abandoned overflow chains, and updates the catalog root page.

cdb_status cdb_db_compact(cdb_db *db, size_t page_limit, size_t *pages_freed);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Open database handle. Must be open and write-capable. Caller owned.
2nd page_limit size_t [In] Maximum number of fragmented pages to process in this incremental invocation. Pass 0 to compact until complete; or limit (e.g. 100) for time-sliced maintenance. Passed by value.
3rd pages_freed size_t* [Out] Pointer to size_t receiving the number of pages reclaimed and returned to freelist. Must not be NULL. Caller allocated.

Returns: CDB_OK on successful compaction; CDB_E_READ_ONLY if database is read-only.

C99 Usage Example: 
size_t freed = 0;
cdb_status s = cdb_db_compact(&db, 256, &freed);
cdb_db_take_entry STATUS

Atomically increments and returns the next unique 64-bit entry ID for store store_id. Updates dirty flags so that the catalog high-water mark will be persisted on the next commit.

uint64_t cdb_db_take_entry(cdb_db *db, uint64_t store, uint64_t *next_entry, int *dirty);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Open database handle. Must have open transaction. Caller owned.
2nd store uint64_t [In] Store ID for which to reserve an entry ID. Valid store ID. Passed by value.
3rd next_entry uint64_t* [Out] Optional pointer to receive entry ID. Can be NULL if return value is used. Caller allocated.
4th dirty int* [Out] Flag set to 1 if catalog metadata was marked dirty. Must not be NULL. Caller allocated.

Returns: The 64-bit unique entry ID assigned to the new record.

C99 Usage Example: 
int dirty = 0;
uint64_t eid = cdb_db_take_entry(&db, store_id, NULL, &dirty);

5. Transactions & Operation Scopes (cdb_db.h)

cdb_tx_begin CREATE

Allocates a private transaction ID, captures the current global commit sequence number for MVCC snapshot isolation, and initializes the in-memory staging delta track for mutations.

cdb_status cdb_tx_begin(cdb_db *db, unsigned durability_mode);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Open database handle. No other active transaction on this handle. Caller owned.
2nd durability_mode unsigned [In] Durability fence guarantee on commit. CDB_DURABILITY_NORMAL (sync at commit), CDB_DURABILITY_RELAXED (group commit / deferred sync), CDB_DURABILITY_MEM_ONLY (test mock). Passed by value.

Returns: CDB_OK on successful transaction start; CDB_E_STATE if transaction is already in progress.

C99 Usage Example: 
cdb_status s = cdb_tx_begin(&db, CDB_DURABILITY_NORMAL);
cdb_tx_commit UPDATE

Performs optimistic concurrency collision checks against newer committed transactions, appends dirty records to the journal/delta track, increments global commit high-water mark, and executes sync barrier.

cdb_status cdb_tx_commit(cdb_db *db);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Database handle with active open transaction. Active transaction must be open. Caller owned.

Returns: CDB_OK on successful commit; CDB_E_COLLISION if concurrent transaction modified overlapping keys; CDB_E_IO on disk sync failure.

C99 Usage Example: 
cdb_status s = cdb_tx_commit(&db);
cdb_tx_abort DELETE

Releases all in-memory staging buffers, resets delta offsets, unpins dirty cache pages, and rolls back allocated entry IDs, leaving storage state identical to the pre-transaction snapshot.

cdb_status cdb_tx_abort(cdb_db *db);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Database handle with active transaction to discard. Must have open transaction. Caller owned.

Returns: CDB_OK on successful abort; CDB_E_STATE if no transaction was open.

C99 Usage Example: 
if (error_occurred) cdb_tx_abort(&db);
cdb_db_op_begin STATUS

Acquires internal reader/writer synchronization mutexes, checks coordinator baton validity, and ensures thread-safe access to shared database state.

void cdb_db_op_begin(cdb_db *db);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Open database handle. Must not be NULL. Caller owned.

Returns: None (void).

C99 Usage Example: 
cdb_db_op_begin(&db);
/* internal critical section */
cdb_db_op_end(&db);
cdb_db_op_end STATUS

Releases internal reader/writer synchronization locks and signals condition variables waiting on page cache or journal release.

void cdb_db_op_end(cdb_db *db);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Open database handle. Must follow matching cdb_db_op_begin. Caller owned.

Returns: None (void).

C99 Usage Example: 
cdb_db_op_end(&db);

6. Relational Table Operations (cdb_table.h)

cdb_table_create CREATE

Registers a new relational table in the catalog with typed columns, not-null constraints, default values, primary key specification, and retention window (keep count). Allocates a new store ID.

cdb_status cdb_table_create(cdb_db *db, const char *name, size_t len, const cdb_table_def *def, uint64_t *store);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership
1st db cdb_db* [In/Out] Database handle. Must not be inside an active user transaction. Caller owned.
2nd name const char* [In] Name of the new table. UTF-8 string, 1 to 255 bytes, unique among stores. Caller owned string.
3rd len size_t [In] Byte length of name string. strlen(name). Passed by value.
4th def const cdb_table_def* [In] Definition struct containing columns, types, nullability, defaults, primary key column indexes, and keep count. Valid pointer to cdb_table_def. Caller owned struct.
5th store uint64_t* [Out] Pointer receiving the newly allocated catalog store ID. Must not be NULL. Caller allocated uint64_t.

Returns: CDB_OK on successful table creation; CDB_E_EXISTS if table name already exists; CDB_E_SCHEMA if column definitions are invalid.

C99 Usage Example: 
cdb_table_def def = { .columns = cols, .n_cols = 3, .primary_key = 0, .keep = 0 };
uint64_t tbl_id = 0;
cdb_status s = cdb_table_create(&db, "users", 5, &def, &tbl_id);

Queries the catalog to inspect registered column names, data types, nullability flags, and default values for a specified table store ID.

cdb_status cdb_table_describe(cdb_db *db, uint64_t store, cdb_table_column_info *cols, unsigned cap, unsigned *count);
Position Parameter Type Direction Function & Purpose Options / Range Memory Ownership

2nd store uint64_t [In] Table store ID to describe. Valid existing table store ID. Passed by value.

4th cap unsigned [In] Maximum capacity of cols array. > 0. Passed by value.
5th count unsigned* [Out] Returns the total number of columns written into cols array. Must not be NULL. Caller allocated unsigned.

Returns: CDB_OK on success; CDB_E_NOT_FOUND if store does not exist; CDB_E_BUFFER_TOO_SMALL if cap is less than table column count.
