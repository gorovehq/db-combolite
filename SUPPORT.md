# Getting Support

Thanks for using Combolite. Where to go:

| Need | Where |
|---|---|
| **How-to / usage** | The root [README](README.md) and each package's README; `combolite-core/docs/FAQ.md` and the user/CMBQL manuals. |
| **API reference** | `combolite-core/docs/CRUD_REFERENCE.md`, `combolite-core/docs/api-usage.html`. |
| **On-disk / query spec** | `combolite-core/docs/spec/` (§01–§15). |
| **Build / contributing** | [`CONTRIBUTING.md`](CONTRIBUTING.md) and the authoritative [`CLAUDE.md`](CLAUDE.md). |
| **Bug reports** | Open an issue with the **Bug report** template (pick the affected package). |
| **Feature requests** | Open an issue with the **Feature request** template. |
| **Security vulnerabilities** | **Do not** open a public issue — use the private flow in [`SECURITY.md`](SECURITY.md). |

Please search existing issues first. This is an open-source project maintained on a best-effort
basis; every report is triaged.
